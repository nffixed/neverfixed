## Configs

❗ If your configs don't appear in the menu, make sure they have the **.cfg** extension.

How to do it:

1. Open the config file with Notepad.
2. Click **File → Save As**.
3. Add **.cfg** to the end of the file name.
4. Select **All Files** in the file type dropdown.
5. Save the file and move it to the config folder.
